# Job Portal

A full-stack web application built with Django that connects job seekers with employers. Users can sign up as either an Employer or a Job Seeker, with role-based access to features.

## Features

- **Role-based Authentication** — Custom user model supporting two roles: Employer and Job Seeker
- **Job Management** — Employers can create, update, and delete job postings
- **Job Listings** — Browse all available jobs with detailed descriptions
- **Apply System** — Job seekers can apply to jobs directly from the job detail page
- **My Jobs Dashboard** — Employers can view all jobs they have posted
- **My Applications** — Job seekers can track all jobs they have applied to
- **Admin Panel** — Django's built-in admin interface for backend data management

## Tech Stack

- **Backend:** Python, Django
- **Database:** SQLite
- **Frontend:** HTML, CSS
- **Authentication:** Django's custom user model with role-based permissions
